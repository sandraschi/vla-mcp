# v0.3.1-beta.1

First public beta of **vla-mcp** — VLA bridge for Wall-OSS / WALL-WM / DMuon with fleet orchestration.

## Highlights

- **E2E pipeline** (`vla_pipeline`): worldlabs → yahboom → ingest → numpy export → DMuon dry_run
- **Live Boomy integration**: `boomy_demo=talkbot|draw` via yahboom-mcp REST; IMU + demo transcript → episode telemetry
- **Fleet bridge fixes**: `yahboom_tool` routed through `POST /api/v1/control/tool`
- **X-VLA 0.9B PEFT** adapter prep for edge Raspbot/Boomy agents
- **Job persistence** + training log tail/SSE on dashboard
- **Prefab cards**: status + pipeline run; EventTimeline on `/pipeline`
- **Demo mode**: `start.ps1 -Demo`, `just demo`

## Install

```powershell
git clone https://github.com/sandraschi/vla-mcp
cd vla-mcp
git checkout v0.3.1-beta.1
uv sync --extra dev
.\start.ps1
```

## Live show-floor loop

```text
vla_pipeline(operation='run', live=True, boomy_demo='talkbot')
```

Requires yahboom-mcp **v2.5.0-beta.1** on `VLA_YAHBOOM_MCP_URL` (default `:10892`).

## Known beta limits

- DMuon co-train is dry_run only unless upstream roots are configured
- Worldlabs generate tool name is env-configurable (`VLA_WORLDLABS_GEN_TOOL`)
- Live pipeline falls back to simulated telemetry when peers are unreachable
